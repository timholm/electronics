# 3 Free University Courses to Learn Electronics

A one page reference built from the TikTok photo post "3 courses to learn electronics from top universities" by @meris.veladzic, 13 November 2026.

Live at https://electronics.holm.team, behind Holm ID (edge SSO, Holm ID integration playbook Pattern A).

Contents:

- Caltech EE114, Analog Circuit Design, taught by Prof. Ali Hajimiri (YouTube playlist "New Analog Circuit Design", 91 videos)
- Cornell ECE 4070, Physics of Semiconductors and Nanostructures, taught by Prof. Debdeep Jena (26 videos)
- ETH Zürich, Digital Design and Computer Architecture (Spring 2020), taught by Prof. Onur Mutlu (38 videos, "How Computers Work, from the ground up")
- The first lectures of each course, and an honest note that these are full-length university lectures, not tutorials

The full extraction (every slide's text) is in `video-extraction.md`.
